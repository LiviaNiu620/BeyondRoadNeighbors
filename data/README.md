# Network data

`tntp/` holds the Anaheim and SiouxFalls networks (`*_net.tntp`) and trip tables
(`*_trips.tntp`) from the Transportation Networks for Research collection,
<https://github.com/bstabler/TransportationNetworks>. Link costs follow the BPR form given in
each network file. Set `BRN_DATA` to read networks from another directory.
